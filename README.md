# 🎮 Scape The Abyss

Meu primeiro jogo desenvolvido utilizando Unity e C#.

## 🕹️ Sobre o projeto

Scape The Abyss é um jogo 2D desenvolvido utilizando a Unity.

O projeto foi desenvolvido como forma de aprendizado e prática de
programação, desenvolvimento de jogos e criação de diferentes
mecânicas e sistemas.

## 🛠️ Tecnologias

- Unity
- C#
- Git/GitHub

## ⚙️ Sistemas implementados

- Sistema de movimentação do jogador
- Sistema de itens
- Sistema de fases
- Sistema de checkpoints
- Sistema de respawn
- Sistema de vidas
- Persistência de dados
- Progressão entre fases

## 📚 O que aprendi

Durante o desenvolvimento deste projeto, pratiquei conceitos de
programação em C#, lógica de programação e desenvolvimento de
mecânicas e sistemas utilizando a Unity.
